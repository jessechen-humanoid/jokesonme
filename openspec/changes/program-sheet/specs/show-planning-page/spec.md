## ADDED Requirements

### Requirement: Program sheet entry on show page

The show page SHALL show a 「節目表」 entry linking to that show's program page, displaying the segment count and total duration, or 「還沒有節目表」 when there are no segments.

#### Scenario: Entry summary

- **WHEN** a member opens the 10 月號 show page whose program has 10 segments totalling 128 minutes
- **THEN** the 「節目表」 entry reads 「10 段・共 128 分鐘」 and links to the program page
