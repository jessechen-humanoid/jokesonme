## Why

Jesse 2026-10-22 回饋：整個平台「使用跟閱讀都很困難」，可以大幅改版（含頁面架構），條件是現在看得到的資訊改版後都還看得到，手機與電腦都要好用。具體點名：

- 演出頁的待辦太長、不常看；「演出文件」（rundown／簡報／問卷連結）沒人用；筆記才是最重要的。
- 靈感卡片上「→ 下一場」「其他…」的歸位按鈕又醜又擾人。
- 介面要視覺化、直覺化，每個流程要更短。

實測（375px）：每頁頂端的柿子紅標題卡佔掉約 1/4 螢幕；次要文字 12px、顏色 #8B9184 在米色底上對比偏低；財務分析的金額在數字中間斷行；財務分頁加了「逐筆紀錄」後「財務預估」被擠出畫面；底部導覽沒有圖示；成員年度報表在手機要左右滑。`show_links` 表目前 0 筆，拿掉演出文件不會遺失資料。

## What Changes

- **外框**：拿掉每頁的柿子紅大標題卡，改成精簡頂列（頁名＋頭像，子頁有返回）；分頁切換改成中性的分段按鈕；底部導覽與電腦側欄加上線條圖示；電腦版內容加寬並在演出頁、行事曆用左右兩欄。
- **字級與對比**：四級字級改為 24／17／15／13，次要文字改用 `--ink-2`；金額一律不斷行。
- **演出頁**：筆記放最上面並可直接在頁面上寫（不用開面板）；待辦收成一張摘要卡（未完成件數、最近截止日），點開才展開；**移除演出文件**。
- **演出列表**：下一場用一張視覺化大卡（日期、倒數、筆記數、未完成待辦數），其他場用日期徽章列。
- **筆記（原靈感）**：導覽與頁名改叫「筆記」；預設看「全部」；**拿掉每張卡片的歸位按鈕**，改成卡片上一個安靜的演出標籤（點了換演出），新增筆記改成頁首直接輸入。
- **待辦**：截止日依急迫程度上色（過期／三天內／其他），列更好點。
- **財務**：分頁標籤縮短到一行放得下（收支／逐筆／分析／匯入／預估）；收支列表長備註收成兩行；財務分析的成員報表在手機改為每人一張卡、電腦維持表格。
- 換頁骨架跟著新外框更新。

## Non-Goals

- 不改資料庫結構、伺服器動作的參數與權限；`show_links` 表保留不刪（只拿掉畫面與寫入動作）。
- 不改 LINE 指令（`/靈感`、`/筆記`、`/note` 照舊）。
- 舊版應援匯入頁（`public/legacy`）內部樣式不重寫，只換外框。
- 不牽動 MCP：本平台不在傑比工具組 plugin 內。
